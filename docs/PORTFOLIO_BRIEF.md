# Research hiring committee brief

## Medicare Claims Analytics: Reproducible Python Research

A modular Python research-engineering demonstration developed around the **CMS 2023 synthetic Medicare RIF** schema.

**Demonstrated skills:** synthetic beneficiary/claim ETL; exact claim-level deduplication; record linkage; date/error/payment QA; Poisson HC3 and NB2 descriptive models; command-line reproducibility; unit tests and automated CI.

**Scientific scope:** The examples are generated using an **invented toy fixture**, not the downloaded CMS release. No real patient records, restricted Medicare administrative data or protected health information are used. Outputs illustrate software execution and **cannot support conclusions about actual Medicare populations**.

**Professional relevance:** Demonstrates transferable Econometrics/Python research engineering capabilities for collaborative health-economics work. It does **not** establish extensive experience working with real healthcare claims data.

**Planned validation:** run on official CMS-supplied synthetic files after downloading and inspecting the current user guide; check schema, duplicates, enrollment exposure, audit logs and coverage-bias limitations. A version-controlled R extension may be added separately.
